# Studio Schettino — Website Redesign Concept

Concept di redesign del sito web di **Studio Schettino Ingegneria**, sviluppato come proposta dimostrativa di una nuova esperienza digitale per lo studio.

Il progetto reinterpreta l'identità dello Studio Schettino attraverso un'interfaccia contemporanea, tecnica e minimale, con particolare attenzione a progettazione, infrastrutture, BIM e servizi di ingegneria.

> **Nota:** questo progetto è una concept demo non ufficiale realizzata esclusivamente a scopo di presentazione e portfolio. Non rappresenta il sito web ufficiale di Studio Schettino.

## Concept

L'obiettivo del redesign è creare un'esperienza digitale coerente con il carattere tecnico e professionale dello studio, evitando il classico layout corporate e privilegiando:

- forte gerarchia visiva;
- design editoriale e minimale;
- valorizzazione dei progetti e delle immagini;
- identità visiva legata al mondo dell'ingegneria;
- sezioni dedicate a servizi, team, BIM, verifiche, formazione e recruiting;
- esperienza responsive ottimizzata per desktop, tablet e mobile;
- micro-interazioni e animazioni leggere.

## Tecnologie

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Motion
- Lucide React
- Next/Image

## Sezioni

Il concept comprende:

- Hero
- Studio
- Numeri
- Servizi
- Team
- BIM
- Verifiche progetti
- Formazione e certificazioni
- News
- Recruiting
- Contatti
- Footer

## Responsive Design

L'interfaccia è progettata per adattarsi alle principali risoluzioni desktop e mobile, mantenendo leggibilità, gerarchia e qualità visiva anche su schermi di dimensioni ridotte.
